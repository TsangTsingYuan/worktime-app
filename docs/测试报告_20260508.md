## 一、需要修复的问题 ✅ 已完成

### 1. 密码明文存储在本地 SQLite ✅

- **文件**：`lib/services/database_helper.dart:117`
- **问题**：`password TEXT NOT NULL` 字段直接明文存储用户密码
- **建议**：使用 Web Crypto API 做 SHA-256 摘要后存储，或利用 `package:web` 实现简单加密

### 2. TimerProvider 每秒重建整个 HomeScreen ✅

- **文件**：`lib/providers/timer_provider.dart:73-78`
- **问题**：`Timer.periodic` 每秒触发 `notifyListeners()`，而 `HomeScreen.build()` 中包含 `context.watch<TimerProvider>()`，导致**整个页面每秒重建**，包括今日记录列表、统计概览等无需每秒刷新的部分
- **建议**：将 `TimerWidget` 独立封装，只在内部 watch `TimerProvider`，或使用 `ValueListenableBuilder` 仅更新计时文字

### 3. DropdownButtonFormField `value` 参数已废弃 ✅

- **文件**：`lib/screens/home_screen.dart:63`、`lib/widgets/todo_edit_dialog.dart:99/159`
- **问题**：Flutter 3.33+ 中 `value` 参数已废弃，需改用 `initialValue`
- **影响**：编译期 2 个 info 级别警告

### 4. `dart:html` 已废弃 ✅

- **文件**：`lib/services/file_downloader_web.dart`、`lib/services/reminder_service_web.dart`
- **问题**：使用已废弃的 `dart:html` 库
- **建议**：迁移到 `package:web` + `dart:js_interop`

## 二、性能优化 ✅ 已完成

### 5. `_buildQuickStats()` 每次 rebuild 都重新计算 ✅

- **文件**：`lib/screens/home_screen.dart:504-588`
- **问题**：HomeScreen 每秒 rebuild 时，该方法会重新遍历所有 logs 计算总时长、完成数量和分类分布
- **建议**：将统计部分拆分为独立 Consumer widget，或缓存计算结果

### 6. SyncService 首次同步拉取全部历史数据 ✅

- **文件**：`lib/services/sync_service.dart:14`
- **问题**：`_lastSyncAt` 初始值为 `0`，首次调用 `_pullChanges` 时拉取服务端**全部**工作记录和待办，数据量大时可能耗时较长
- **建议**：初始化时从本地数据库读取最后一次同步时间戳

## 三、用户体验改进 ✅ 已完成

### 7. 无同步状态指示器 ✅

- **问题**：用户无法感知数据是否在同步中、同步是否成功
- **建议**：在 AppBar 或底部添加同步状态小图标/文字

### 8. 修改昵称无成功反馈 ✅

- **文件**：`lib/providers/auth_provider.dart:93-98`
- **问题**：`updateProfile` 成功后没有 SnackBar 提示
- **建议**：在 `settings_screen.dart` 调用处添加 SnackBar

### 9. 手动补录日期选择流程可优化 ✅

- **文件**：`lib/screens/home_screen.dart:222-268`
- **问题**：点击一行触发先选日期再选时间的串联弹窗，交互流程较长
- **建议**：使用 `showDatePicker` + `showTimePicker` 可合并为更紧凑的交互，或预填当前时间减少操作步数
